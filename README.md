# iOS Insight

A Windows desktop diagnostics workspace for iPhone users. Connect an iPhone over USB to review the device information and diagnostics that iOS makes available through trusted-device services.

The complete v0.5.0 source package will be published here. See the package README for installation and usage.

## Important limitations

iOS intentionally restricts access to protected app data, system caches, and live process internals. iOS Insight does not bypass those protections, does not claim to provide a complete malware scan, and does not delete data automatically. Diagnostic fields depend on iOS version, device state, and the services exposed by the connected device.
